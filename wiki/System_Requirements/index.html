Kicksecure System Requirements

Kicksecure System Requirements

Category

Description

Minimum

Meeting Minimum Hardware Requirements

Recommended
  • Additional hard drive space when installing applications into the Kicksecure.

For Best Performance
  • A solid state drive (SSD).
  • Additional RAM to dedicate to the Kicksecure when multitasking. [1]

Additional Notes
  • Kicksecure can be run with 512 MB RAM when not using a desktop environment. [2]
  • 768 MB RAM is required for LXQt desktop to launch. [3]
  • Users that experience the PAE or "VERR_SSM_FIELD_NOT_CONSECUTIVE" error or other problems should refer to the VirtualBox Troubleshooting chapter.

Kicksecure for Qubes System Requirements

Kicksecure-Qubes does not have any special system requirements beyond and above Qubes own system requirements. In other words, it is only necessary to fulfill the minimal system requirements for Qubes compatibility.

Refer to the Qubes documentation for further information:

  • Qubes System Requirements (.onion)
  • Qubes Certified Hardware (.onion)
  • Qubes OS Forum: Community-recommended computers
  • Qubes Hardware Compatibility List (HCL) (.onion)
