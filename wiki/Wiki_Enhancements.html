Installed Mediawiki Extensions

Apart from our own original upgrades, we have hand-picked and installed numerous extensions to introduce more features to all users and to increase accessibility. The pre-installed extensions of the MediaWiki standard installation are omitted here for brevity.

  1. CodeMirror improves the editor experience with optional syntax highlighting
  2. Comments allows user comments on pages where the special comments-tag is present
  3. ContactPage offers a comprehensive and easy way for visitors to contact our team
  4. CookieToBodyClass is a MediaWiki extension created by our team. This allows developers to mirror cookies as a class for the body element, which is used to prevent "style jumps" when the page is loading. Here is the documentation for CookieToBodyClass
  5. CookieWarning implements the EU-mandatory warning for users that cookies are used
  6. CSS allows custom CSS to be added to specific pages by developers to improve the user experience
  7. DarkMode offers the option for users to view the page in dark mode / night mode
  8. DisableAccount gives admins the power to ban malicious accounts and thereby secure the integrity of the wiki
  9. Flagged Revisions offers visitors, even anonymous ones, the ability to edit our pages and contribute, and gives these contributions to editors and admins for a safe revision before publication
  10. HeadScript allows us to implement custom CSS, JS, favicons, other libraries, fontAwesome, etc. for more functionality on the wiki
  11. LinkSuggest suggests links to editors, making the editing process a little bit faster and more efficient
  12. LinkToArchive adds to external links on the wiki an automatic link of the Web Archive version of this URL
  13. Lockdown improves wiki security by offering a more finely grained restriction model
  14. MsUpload introduces a handy drag-and-drop upload area for files to improve the editor experience
  15. New Signup Page enhances MediaWiki's default signup page
  16. Previews displays preview popups when the user hovers over a link
  17. Revision Slider adds a more comfortable, more practical slider interface to the diff view for editors
  18. Rotten Links helps keep the wiki clean by preventing dead links on the wiki by showing the admin a table of all external links on the wiki with their status
  19. User Merge allows the admin to merge different user accounts, for example, if a user created duplicate accounts by accident, account reconciliation, and other scenarios alike that might occur for contributors and other users
  20. Widgets offers developers the opportunity to add true HTML fragments to our pages. This is used to create well-designed special pages for our users that would not be achievable with the standard wiki syntax
  21. WikiSEO allows us to create and maintain high-level SEO optimizations for our wiki so they can be found more easily by new users
