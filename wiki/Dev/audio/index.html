  • Debian 12 on Virtualbox with Intel HD Audio will result in non-loading videos - reports that AC97 works better than Intel HD.

Debian bug reports

  • Debian 12 in VirtualBox with Intel HD Audio, PipeWire, and 4 GB RAM causes videos to fail loading

QEMU / KVM bug reports

  • KVM forum: No audio with SPICE + pipewire, halts with ALSA, Qemu pipewire unsupported

VirtualBox bug reports

  • https://www.virtualbox.org/ticket/20634

Summary of PipeWire Sounds Issues inside VirtualBox

Intel HD Audio:

  • plain Debian/Kicksecure/possibly Arch Linux + 2GB RAM: functional
  • plain Debian/Kicksecure/Arch Linux + 4+GB RAM: broken

AC97:

  • ac97 + Debian/Kicksecure + any GB = functional

Error and Warnings

mod.rt: Can't find org.freedesktop.portal.Desktop. Is xdg-desktop-portal running?

pipewire[1578]: mod.rt: Can't find org.freedesktop.portal.Desktop. Is xdg-desktop-portal running?
pipewire[1578]: mod.rt: found session bus but no portal
  • Not a problem in Kicksecure 18 with LXQt.
    • LXQt provides its own XDG desktop portal backend, xdg-desktop-portal-lxqt, and uses other portal backends where necessary.
  • Prior to Kicksecure 18, out-of-date and retained for reference only:
    • Non-Qubes Debian based issue only. Xfce issue only.
    • Qubes Debian based does not have this issue.
    • missing package: xdg-desktop-portal and probably also xdg-desktop-portal-gtk
    • problem is that Xfce does not have its own XDG desktop portal implementation. Therefore the xdg-desktop-portal systemd user unit does not autostart by default. Not applicable to LXQt.
      • manual workaround: systemd --user start xdg-desktop-portal
      • xdg-desktop-portal-gtk is a good choice as per https://github.com/flatpak/xdg-desktop-portal/pull/1199
      • Xfce does not provide an XDG Desktop Portal by default.
        • Please provide an xfce-portals.conf for xdg-desktop-portal >= 1.17)
        • Does xdg-desktop-portal-xfce exist, or should it exist?
      • TODO research: how to implement this by default as a Linux distribution
        • in Debian trixie perhaps https://packages.debian.org/trixie/xdg-desktop-portal-xapp would work
    • Fixed by Kicksecure/kicksecure-meta-packages
