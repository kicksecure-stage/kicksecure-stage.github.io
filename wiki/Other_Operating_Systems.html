How to distribution-morph Other Operating System into Kicksecure?

Can I install Kicksecure on a Debian-based distro like SpiralLinux? Unsupported.

Packages by Kicksecure are designed to be easily re-usable on Debian stable, the current version on which Kicksecure is based. See also Packages for Debian Hosts. The Kicksecure source code should even be easily re-usable by non-Debian-based Linux distributions, but that requires a distribution developer and is too difficult for users.

However, the more different the Linux distribution is, the more difficult this gets due to dependency issues or perhaps other problems.

Users are free to experiment with this. Security issues (as in creating remotely exploitable security vulnerabilities) are unexpected. However, other grave usability issues such as, in the worst case, a Broken Boot are conceivable.

Kicksecure developers won't be able to debug issues on all sorts of Linux distributions. Therefore, this is classified as Unsupported.
